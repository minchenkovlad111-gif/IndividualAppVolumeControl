# Magisk module

This module installs the App Volume Control APK as a privileged system app and grants required permissions.

## Install
1. Build the APK (`docs/BUILD.md`).
2. Copy it to `module/system/priv-app/AppVolumeControl/AppVolumeControl.apk`.
3. Zip the `module/` folder and flash via Magisk.
4. Or run `module/package.sh` to copy the APK and create the zip.
